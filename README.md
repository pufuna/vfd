# PUFVFD — преобразователь частоты 1,5 кВт

Вход: 1 фаза 220 В. Выход: 3 фазы 0…220 В, 0…200 Гц. Скалярное (U/f) и бездатчиковое векторное управление, ПИД-регулятор, ЖКИ 20×4 на русском языке, Modbus RTU, Wi-Fi (веб-интерфейс, Modbus TCP), Bluetooth, корпус для 3D-печати.

> **Статус проекта.** Это комплект конструкторской документации и программного обеспечения. Алгоритмы управления проверены на математической модели двигателя, обе прошивки собираются, печатная плата разведена и проходит проверку правил KiCad без замечаний. **Устройство не собиралось, плата не изготавливалась, на реальном железе ничего не испытывалось.** Плата разведена автоматически и не проходила ревью человеком. Подробности — в `docs/01_description.md` (разделы 3.6 и 4.2).
>
> В устройстве действуют опасные напряжения. Сборка и наладка требуют квалификации для работы с сетевым напряжением.

## Основные решения

- Силовая часть: мост KBPC3510, шина 3 × 470 мкФ 400 В, интеллектуальный модуль IGBT IKCM30F60GA (600 В, 30 А) с встроенной защитой от КЗ, автономный тормозной ключ.
- Управление: STM32F411 на гальванически развязанной стороне; развязка ШИМ оптронами HCPL-2630, токи — датчиками Холла ACS712, напряжение шины — изолирующим усилителем.
- Связь: ESP32 как необязательный модуль; привод работает и без него.
- Единый источник данных: схема описана в `hardware/netlist.py`; из него получаются чертежи (с автоматической сверкой связности), перечни и плата.
- Ориентировочная стоимость комплектующих — около 14 850 ₽ (см. `docs/bom.md`; цены и наличие по каталогам не сверялись).

## Пересборка

Чертежи и перечни:

```bash
python3 hardware/gen.py
```

```bash
python3 hardware/sch/docs.py
```

Плата (размещение, трассировка, полигоны и DRC, выходные файлы; нужен KiCad 7 с модулем `pcbnew`):

```bash
python3 hardware/pcb/make_pcb.py place
```

```bash
python3 hardware/pcb/make_pcb.py route
```

```bash
python3 hardware/pcb/make_pcb.py finish
```

```bash
hardware/pcb/export.sh
```

Тесты прошивки и таблица параметров:

```bash
make -C firmware/sim test docs
```
