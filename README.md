# ПЧ-1500 — преобразователь частоты 1,5 кВт

Вход: 1 фаза 220 В. Выход: 3 фазы 0…220 В, 0…200 Гц. Скалярное (U/f) и бездатчиковое векторное управление, ЖКИ 20×4 на русском языке, Modbus RTU, Wi-Fi (веб-интерфейс, Modbus TCP), Bluetooth, корпус для 3D-печати.

> **Статус проекта.** Это комплект проектной документации и программного обеспечения. Алгоритмы управления проверены на математической модели двигателя, обе прошивки собираются. **Устройство не собиралось и на реальном железе не испытывалось; трассировка печатной платы не выполнена.** Подробности — в `docs/01_description.md` (раздел 4.2) и `docs/02_assembly.md` (раздел 2).
>
> В устройстве действуют опасные напряжения. Сборка и наладка требуют квалификации для работы с сетевым напряжением.

## Основные решения

- Силовая часть: мост KBPC3510, шина 3 × 470 мкФ 400 В, интеллектуальный модуль IGBT IKCM30F60GA (600 В, 30 А) с встроенной защитой от КЗ, автономный тормозной ключ.
- Управление: STM32F411 на гальванически развязанной стороне; развязка ШИМ оптронами 6N137, токи — датчиками Холла ACS712, напряжение шины — изолирующим усилителем.
- Связь: ESP32 как необязательный модуль; привод работает и без него.
- Ориентировочная стоимость комплектующих — около 14 700 ₽ (см. `docs/bom.md`; цены требуют уточнения).
